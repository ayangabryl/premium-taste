# Portfolio-grade jury bar

If a senior design jury scored a page today, they'd likely say:

> **Strong interaction concept. Execution reads template — not portfolio-grade.**

Honorable mention **idea**. Not **craft**.

## What jury would cite (fail)

| Issue | Our pattern | Jury expectation |
|---|---|---|
| **Color** | Warm black + gold/copper accent | Committed system — monochrome, one ink, or unexpected accent used once |
| **Material** | Flat gradients, glow handles, CSS "premium" | Texture, print quality, photography, or generative art with discipline |
| **Typography** | Safe pairings (Newsreader + JetBrains, Fraunces + IBM) | Distinctive voice, optical sizing, scale tension — not "big serif h1" |
| **Glow** | Box-shadow halos on dividers/cursors | Light comes from layout and contrast, not CSS glow |
| **Code aesthetic** | Rainbow syntax theme | Syntax colors are part of the brand system — desaturated, limited |
| **Concept vs finish** | 8/10 idea, 5/10 surface | Both must be 8+ |

## Jury scorecard (honest self-grade)

| Surface | Concept | Visual craft | Would jury honor? |
|---|---|---|---|
| Reference remix 404 | 7 | 6 | Unlikely |
| Interaction-led hero | 8 | 6 | Maybe — interaction saves it |
| Portfolio split | 8 | **5** | No — gold-on-black dev template |

## Premium means (jury lens)

1. **One color strategy** — restrained OR committed, never "dark + gold accent"
2. **No glow as decoration** — shadow and light are structural
3. **Typography is the brand** — not a font pairing from a list
4. **Custom material** — grain, print, photo, generative — not gradient mesh
5. **Restraint** — remove until it breaks, then add one thing back
6. **Cohesion** — code pane matches design pane system (same accent, same gray scale)

## Before ship — jury questions

1. Would this survive next to today's best portfolio work? (Honest: probably not yet.)
2. Can you name the color strategy in one word? (Monochrome / Ink / Signal / Paper)
3. Is the accent used ≤10% of pixels?
4. Would removing all box-shadow still feel designed?
5. Is the concept visible in a 3-second squint?

## For agents

Do not stop at `premium-taste verify` pass. Pass verify, then run this jury checklist. If craft ≤6, iterate surface before shipping.
