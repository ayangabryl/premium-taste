# Premium Taste purpose

**Premium Taste is a designer-first creative engine** — it helps AI agents invent UI that fits the product, at a senior creative courage bar, without cloning references or picking aesthetic presets.

## What we are NOT

| Approach | What it does | Why Premium Taste differs |
|---|---|---|
| **Design-system tools** | Pick a brand system → apply tokens | Premium Taste does not route you to lookalike presets |
| **Polish tools** | Shape brief + refine existing UI | Premium Taste adds phased build + verify/jury for creative courage |
| **Reference feeds** | Copy what looks cool | Premium Taste uses refs for **courage calibration only** |

If output looks like the reference you fed — **we failed**, even if verify passes.

## Designer-first workflow

1. **Product discovery** — who, job, moment, differentiation (before any visual choice)
2. **Concept sentence** — one metaphor tied to the product (agent-written, not template)
3. **Originality test** — *"This looks like ___ with different copy"* — if namable, reject
4. **Build in phases** — layout → assets → motion → interaction → polish
5. **Verify + jury** — craft gates + honest self-score on product fit and originality

Tastes and techniques are **internal scoring vocabulary**, not menus for users to pick from.

## What Premium Taste is

- A **product-fit director** — briefs ask questions, not prescribe dither/scrub/editorial
- A **courage bar** for senior creative work — reduction, type, motion with purpose
- An **originality guard** — similarity traps on references, anti clone in phases

## What it is NOT

- A design-system picker
- A technique catalog ("steal monumental type + generative geometry")
- A guarantee of awards — human eye + honest jury.md still matter

## Success looks like

- Same product brief → **different** visual directions across runs (not convergent demos)
- Auth screen fits auth job — not "cool OTP because dither demo exists"
- Agent cites product discovery answers in concept — not taste lane name
- `premium-taste jury` fails pages that are cool but wrong for the product
