# Senior creative designer bar

Before shipping any page, score yourself honestly. **7+ on all rows** or rebuild.

| Dimension | 4/10 (AI slop) | 8/10 (senior creative bar) |
|---|---|---|
| **Concept** | "Dark hero with gradient" | ONE sentence metaphor — everything serves it |
| **Reduction** | Headline + sub + visual + badges + CTA | 3 elements max. Empty space is intentional. |
| **Type** | Inter/Syne at normal h1 size | Type IS the interaction — scale, crop, variable voice, optical sizing |
| **Color** | Purple mesh gradient | ONE committed field OR monochrome discipline |
| **Mark** | Stock illustration / orb nodes | One human or generative mark with meaning |
| **Copy** | "Build 10x faster" | Poetic, sharp, or silent — never SaaS Mad Libs |
| **CTA** | Centered pill button | Corner, underline, or ghost — never the hero |
| **Motion** | Everything fades in | Misregistration settles, draw-on, ambient with purpose |

## Originality test (non-negotiable)

Before shipping, finish this sentence honestly:

> "This looks like ___ reference with different copy."

If you can name a curated reference or a generic SaaS template → **reject and restart**.

Original creative ≠ remix. Same **bar** (courage, reduction, craft). New **grammar** (layout mechanic, color world, copy voice).

### Typography bar (creative mode)

**Task UI (auth, checkout, payment, pricing):** sans-first — one distinctive sans family, product-scale headlines, tabular nums on prices. No Fraunces/editorial serif on forms.

**Spectacle surfaces (404, hero type-as-image):** display voice with personality — condensed grotesk, stencil, or intentional serif when type IS the visual — not Syne/Inter/DM Sans template stacks.

## The senior test

1. Squint at the page — can you still read the **one idea**?
2. Cover the logo — does it still feel designed?
3. Compare to reference screenshot — same **courage**, not same layout?
4. Would you put this in a design portfolio?

If any answer is no → not done.
